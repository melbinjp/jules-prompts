# Jules Prompts

A curated library of pre-made, machine-readable task prompts that let Jules (or any agent) — and humans — turn intent into production-grade work.

## Getting Started

To learn about the prompts in this library and how to use them together, please see the [Jules Prompt Library Guide](./PROMPTS_GUIDE.md).

## Programmatic Access

This repository includes a `prompts.json` file that provides a machine-readable index of all available prompts. This is useful for AI agents or other tools that need to discover and fetch prompts programmatically.

Each entry in the JSON file includes a title, a short description, and the path to the prompt file.
