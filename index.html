Recommended Workflow

The prompts in this library are designed to be used together in a logical sequence. Here is a recommended workflow for taking a new or unmaintained project to a production-ready state:

  1. Audit the repository with task_audit_repo.md to get a deep understanding of the project's current state.
  2. Harden the repository with task_harden_repo_initial.md to set up a modern CI/CD pipeline and testing infrastructure.
  3. Fix and refine the codebase with task_fix_and_refine.md to address any bugs or architectural issues.
  4. Perform ongoing maintenance with task_harden_repo_iterative.md and task_update_dependencies.md.
