One conductor for delivering any project, with evidence.

A single Agent Skill that takes a project, software, physical, service or hybrid, from nothing or from any existing state to an accepted result, and hands over whatever must keep running. It loads focused guidance only when the work needs it, and counts nothing as done without evidence about the actual result.

Read the conductor Point an agent here

Works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Jules, and agents that drive hardware. Free and MIT licensed, with no sign-up and no tracking.

What it does

It classifies the project from evidence, then works through eight responsibilities and returns to any of them when the evidence changes. Where it starts is decided by what the project lacks, not by a label.

{% include conductor-loop.html %}

The conductor also covers work records, readiness, gates, changes, authority and budget, closure and handover, and how a report ends.

Guidance it loads when the work needs it

Each file is one part of the loop, and the conductor says when to load it. On a small context window it loads one file at a time, and only the sections the work needs.

Clients that support Agent Skills discovery can start from /.well-known/agent-skills/index.json, which lists the conductor as an archive of the whole folder with a SHA-256 digest.

The whole folder

mkdir -p .agents/skills/conductor
curl -fsSL {{ '/.well-known/agent-skills/conductor.zip' | absolute_url }} -o conductor.zip
unzip -q conductor.zip -d .agents/skills/conductor

From a clone

git clone --depth 1 https://github.com/melbinjp/jules-prompts
cp -R jules-prompts/conductor .agents/skills/

Copy the whole folder: SKILL.md alone is incomplete, because it refers to the guidance and templates. Use .claude/skills/ for Claude Code and .agents/skills/ for Codex and other agents that read AGENTS.md. Paste the standing rules into a project's AGENTS.md so they apply even when nobody loads the conductor.

How you know it works

A procedure nobody has seen fail is a claim. The repository keeps 26 regression fixtures: small projects with planted defects and a list of them. Run an agent on one with the conductor, and scripts/score_fixture.py says which defects its report named, which it missed and which it made up. This is the report one fixture should produce:
